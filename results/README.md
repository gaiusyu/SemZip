# Measured results

`final/` contains the completed strict main experiment: all 96 complete-file outcomes and 216 observations in 72 three-repeat formal cells. All pass, with repeated archives equal to the accepted first pass. It also contains the matched four-dataset representation control and separately scoped offline construction/sampling records. `suffix/` is a cost view of original nontraining blocks; it is not a new codec experiment or a timing cohort.

Use `integration/render_saved_results.py` to reproduce final tables and figures from the anonymous numeric records. Historical experiments remain separate under `historical_evidence/` and `historical_figures/`. Original failures, superseded instrumentation outcomes and their controls are retained separately, not pooled into final statistics.
