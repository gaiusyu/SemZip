# Bounded validation controls

These controls are separate from performance experiments and never change a deployed program, storage policy, measured archive or original outcome.

- `r67_cold_observer/`: every saved B1/B2 observation and trigger in the seven-dataset historical follow-up is unchanged under explicit cache/callable reset. This finite 14-block equality does not relabel the historical pipeline as the R71 protocol. Only anonymous evidence is shipped, not the original block/group/plan bundle.
- `fresh_response_boundary/`: the complete sixteen-dataset local UTC0/C response-content control has 14 exact plan matches and two retained differences. Two additional, separately labeled Asia/Shanghai controls explain Linux/Mac and match both original plan files. All 28 original counterexample timestamps match the historical Shanghai offset. This does not erase the missing original training-time TZ pin or constitute HTTP/provider replay.

The latter subtree ships a package-relative fixed eighteen-condition suite and explicit-path single-condition helpers. The suite and its actual package-only validation are documented in `fresh_response_boundary/README.md`. For one condition, from the artifact root (with a new output path):

```sh
mkdir -p ../control_runs
PYTHONDONTWRITEBYTECODE=1 PYTHONHASHSEED=0 python3 validation_controls/fresh_response_boundary/tools/replay_utc0.py \
  --source source --evidence offline_evidence --dataset Proxifier \
  --expected-plan deployments/Proxifier/program.json --output ../control_runs/Proxifier
```

A fresh process per dataset is required. The explicit-timezone helper additionally requires `--timezone UTC0` or `--timezone Asia/Shanghai`. These tools replace the model boundary with exact saved response content, forbid known Python network entry points and stop after the unchanged plan writer. They do not replay provider transport or reconstruct historical environment metadata.

- `formal_inventory/`: complete superseded V2 schedule, retained output identities and observed/synthetic metadata controls supporting the uniform V3 auditor correction. No superseded timing is pooled into final results.
