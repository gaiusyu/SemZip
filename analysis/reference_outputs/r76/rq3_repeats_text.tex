To test whether the narrow wins survive a fresh draw of the whole pipeline, we reran it twice more on the four files where \tool\ led DeLog by 2--6\% (Table~\ref{tab:repeats}), with five new syntheses, gate, selection, storage fitting, and complete-file encoding each time. All 12 runs are smaller than DeLog on both the complete file and the suffix, and complete-file ratios differ across runs by at most 3.9\%. Selection thus reproduces these four comparisons although individual syntheses differ widely. Thunderbird, which decides summed bytes, was not rerun.
