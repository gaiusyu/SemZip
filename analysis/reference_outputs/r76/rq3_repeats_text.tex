To test whether the narrow wins survive a fresh draw of the whole pipeline, we rerun it twice more on the four files where \tool\ led DeLog by 2--6\% (Table~\ref{tab:repeats}). Each rerun uses five new syntheses, gate, selection, storage fitting, and complete-file encoding. All 12 runs are smaller than DeLog on both complete file and suffix, and complete-file ratios differ across runs by at most 3.9\%. We did not rerun Thunderbird, which decides summed bytes. Selection thus reproduces these four comparisons, although individual syntheses differ widely.
